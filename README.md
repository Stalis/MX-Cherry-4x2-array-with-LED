# MX Cherry 4x2

Компактный модуль клавиатуры на 8 переключателей Cherry MX: 4 столбца × 2 строки. Он не содержит микроконтроллера и предназначен для подключения к внешнему контроллеру или макетной плате.

## Возможности

- 8 посадочных мест Cherry MX 1U с шагом 19.05 мм.
- Клавишная матрица 4×2 с отдельным диодом на каждую клавишу.
- Матрица 4×2 из восьми светодиодов, по одному на клавишу.
- Две параллельно подключённые SMD-гребёнки `J1` и `J2`: 2×10, шаг 2.54 мм, на нижней стороне платы.
- Двухслойная плата толщиной 1.6 мм, габариты 78.74 × 38.10 мм.

## Матрицы

Клавиши расположены так:

|       | `COL_0` | `COL_1` | `COL_2` | `COL_3` |
| --- | --- | --- | --- | --- |
| `ROW_0` | SW1 / D1 / RLED1 | SW2 / D2 / RLED2 | SW3 / D3 / RLED3 | SW4 / D4 / RLED4 |
| `ROW_1` | SW5 / D5 / RLED5 | SW6 / D6 / RLED6 | SW7 / D7 / RLED7 | SW8 / D8 / RLED8 |

У каждой клавиши последовательно включён диод `D1…D8`; это устраняет ghosting при сканировании матрицы. Светодиоды `RLED1…RLED8` образуют независимую матрицу с теми же 4 столбцами и 2 строками.

## Подключение

`J1` и `J2` электрически идентичны: можно использовать любой из них или оба для монтажа модуля. Нумерация соответствует стандартному разъёму 2×10 с нечётными контактами в одном ряду и чётными в другом.

| Контакт | Сигнал | Назначение |
| --- | --- | --- |
| 1 | `SW_0_ROW_0` | строка 0 клавишной матрицы |
| 2 | `LED_0_ROW_0` | строка 0 LED-матрицы |
| 3 | `SW_0_ROW_1` | строка 1 клавишной матрицы |
| 4 | `LED_0_ROW_1` | строка 1 LED-матрицы |
| 5–12 | NC | не подключены |
| 13 | `SW_0_COL_0` | столбец 0 клавишной матрицы |
| 14 | `LED_0_COL_0` | столбец 0 LED-матрицы |
| 15 | `SW_0_COL_1` | столбец 1 клавишной матрицы |
| 16 | `LED_0_COL_1` | столбец 1 LED-матрицы |
| 17 | `SW_0_COL_2` | столбец 2 клавишной матрицы |
| 18 | `LED_0_COL_2` | столбец 2 LED-матрицы |
| 19 | `SW_0_COL_3` | столбец 3 клавишной матрицы |
| 20 | `LED_0_COL_3` | столбец 3 LED-матрицы |

Контроллер должен сканировать матрицы внешней логикой. На плате нет токоограничивающих резисторов для светодиодов: обязательно ограничьте ток внешней схемой или драйвером LED.

## Комплектующие

| Количество | Обозначения | Посадочное место |
| --- | --- | --- |
| 8 | `SW1…SW8` | Cherry MX 1U, PCB mount |
| 8 | `D1…D8` | SOD-323F |
| 8 | `RLED1…RLED8` | LED 1206, 3216 Metric |
| 2 | `J1`, `J2` | SMD socket 2×10, 2.54 мм |

Номиналы диодов и цвет/электрические параметры светодиодов не заданы в схеме: выберите их под напряжение и ток внешнего драйвера.

## Файлы репозитория

- `MX Cherry 4x2.kicad_pro` - проект KiCad.
- `MX Cherry 4x2.kicad_sch` - главная схема.
- `MX Cherry 4x2.kicad_pcb` - разводка платы.
- `switch_module.kicad_sch` и `led_module.kicad_sch` - повторно используемые листы одного переключателя с диодом и одного LED.
- `jlcpcb/` и `production/` - ранее экспортированные производственные файлы.

> Производственные BOM/CPL в `jlcpcb/` и `production/` устарели относительно текущих схемы и платы: в них нет `RLED1…RLED8`, а разъёмы описаны как 1×10. Перед заказом заново экспортируйте Gerber, BOM и CPL из текущего проекта.

## Открытие и проверка

Проект создан в KiCad 10. Откройте `MX Cherry 4x2.kicad_pro` в KiCad или проверьте его из командной строки:

```sh
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli sch erc "MX Cherry 4x2.kicad_sch"
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli pcb drc --schematic-parity "MX Cherry 4x2.kicad_pcb"
```
